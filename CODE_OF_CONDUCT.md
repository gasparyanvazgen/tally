# Code of Conduct

## Our Commitment

Tally welcomes contributors with different backgrounds, experience levels, and perspectives. We are committed to a respectful, professional, and constructive environment.

## Expected Behavior

- Be respectful and professional.
- Communicate clearly and constructively.
- Focus feedback on code or ideas, not people.
- Accept constructive criticism.
- Respect different opinions and approaches.
- Help create a welcoming environment for new contributors.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, deliberate disruption, publishing private information without permission, sexualized/inappropriate behavior, and other behavior that makes contributors reasonably feel unsafe or unwelcome are not acceptable.

## Issues and Pull Requests

Use GitHub Issues and Pull Requests for constructive collaboration. Explain technical disagreements with reasoning and evidence where possible. Avoid personal criticism.

## Enforcement

Maintainers may request changes, close issues/discussions/PRs, temporarily restrict participation, or permanently restrict participation for serious or repeated violations.

## Reporting

Report unacceptable behavior privately to the project maintainer. For security vulnerabilities, follow [SECURITY](SECURITY.md) instead of using a public issue.

## Final Principle

**Attack the problem, not the person.**
